# Getting Started with Next.js 16

Next.js 16 brings significant improvements to the framework. Here's what you need to know.

## Key Features

- **Improved Server Components**: Better performance and smaller bundle sizes
- **Dynamic Params as Promises**: Cleaner handling of dynamic route parameters
- **Enhanced Streaming**: Faster initial page loads with selective prerendering

## Getting Started

1. Install Next.js 16
2. Create a new project
3. Start building!

This is exciting stuff.
