# My Portfolio Site

I built this entire site from scratch using Next.js 16, Tailwind CSS, and Markdown.

## What's Included

- A blog for long-form content
- A projects section to showcase my work
- An offers section for products and services
- Custom landing pages for campaigns

## Tech Stack

- Next.js 16
- React 19
- TypeScript
- Tailwind CSS
- Markdown with frontmatter

The site is fully static-generated and deployed on Vercel, which means it's incredibly fast and scales automatically.
